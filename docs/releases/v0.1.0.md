# Daybook v0.1.0 · 首次试用版

离线安卓个人日历：统一记录安排、截止任务和生活片段。

- 月历、当天列表、未安排任务和近期 DDL。
- 新增、编辑、任务完成与恢复、删除及短时撤销。
- JSON 导出、恢复预览、确认替换和替换前快照。
- 无账号、无联网权限；不包含系统通知或自动同步。

安装附件 `daybook-v0.1.0.apk`，要求 Android 8.0+。应用初始为空。右上角菜单用于备份；以后升级请覆盖安装，不要先卸载。

已通过 15 项单元测试、8 项 Android 15 模拟器测试、Lint、同签名覆盖安装和 release 启动检查。品牌真机与两周实际试用尚待完成。

源码、使用说明、验收记录和每个里程碑的开发提交均保存在仓库中。安装包校验值见附件 `SHA256SUMS.txt`。
