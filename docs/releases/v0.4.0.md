# Daybook v0.4.0

这次更新让随手记录更方便，也让日历可以换上自己的背景。

- 独立便签入口：无需标题和日期，正文自动保存，返回确保保存；支持可选日期、独立提醒和通知直达。便签不属于第四种记录类型，不混入日历、任务或回顾。
- 自选背景图片：预览后应用，本机提取主题色，按钮与选中态随之变化；四主页共享背景，编辑/设置保留清晰底色，可恢复默认。
- 日历年月合为一行，支持跟手换月和短滑回弹；统一“具体时间未定”文案。
- 增加重置筛选，同时清空条件、搜索词和已应用结果。
- 首次通知授权与一次可跳过提醒引导，提醒设置中提供多品牌自启动/后台和悬浮通知建议，不统一要求“无限制”省电策略。
- 备份升级为 JSON 4，包含原记录、便签与提醒，读取 JSON 1–4；恢复旧备份会清空便签，确认页明确提示并先保存完整快照。背景与配色是本机偏好，不进入记录备份。

Android 8.0+，无账号、无联网权限。原签名保持不变，真实 v0.3.0 → v0.4.0 覆盖升级通过；直接安装新 APK，勿先卸载，建议先导出备份。

39 项 JVM 单测、分阶段 UI/迁移/备份/通知/外观专项、大字体与软键盘、正式 Release 覆盖升级通过。真机后台提醒仍受厂商系统策略影响；既有提醒异常的长期复现按用户要求暂缓。没有开展完整 QA 或其他 backlog。
