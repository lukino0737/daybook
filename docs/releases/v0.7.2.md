# Daybook v0.7.2

这次改进提醒列表、图文编辑、通知预览与日历空白区域。

- 提醒列表支持左滑后确认删除。独立提醒整条删除；任务、日程和便签只取消附带提醒，原内容保留。
- 正文在同一个编辑框中连续输入，图片插入光标处、独占一行，下一行继续文字；支持图片查看、移除和跨图文选区。事项显式保存、便签自动保存方式不变。
- 通知预览改为模糊背景上的居中卡片，左上退出、右上编辑，长内容在卡片内滚动。
- 日历选中日期没有可显示内容时，隐藏日期标题、节假日说明和空提示卡片；月历、近期截止及新增按钮保留。

Android 8.0+，版本0.7.2/code10，Room6/ZIP JSON6不变。普通功能可离线使用，可选AI功能继续由用户在设备内配置DeepSeek API Key。

建议先导出备份，再直接覆盖安装APK，勿先卸载。APK沿用原签名，源码ZIP对应本次发布提交；SHA256清单用于核验附件。

实现阶段69项JVM通过、Lint无错误；API35普通字号30个不同专项分批通过，150%字号9项通过，包含真实系统选图与宿主重建。真实DeepSeek、真机及API26实际运行未验证；模拟器结果不代表所有机型。详细验证范围见docs/TESTING.md。
