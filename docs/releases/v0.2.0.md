# Daybook v0.2.0 试用版

新增本地提醒、标签回顾与正文搜索，手机固定竖屏。

- 安排/任务可独立设置提醒时间，点击通知打开记录。请在“提醒设置”开启通知和准时提醒权限。
- 生活记录支持多标签；“回顾”可按标签、标题和正文找回内容。
- “未安排”改名“无截止”并明确范围；“待完成”显示数量。
- 可读取旧备份，同签名覆盖安装保留原记录。

**升级：先导出备份，再直接安装新版 APK，不要先卸载。** 新版备份不能交给旧版恢复。

27 项单测与 15 项模拟器功能用例通过；另验证权限拒绝、进程退出与重启提醒、大字体及真实 v0.1.0 覆盖升级。品牌手机后台表现仍需试用；系统强行停止后须重新打开 App。未加入生日重复、照片、自定义背景。

校验值见 SHA256SUMS-v0.2.0.txt。详细验收见仓库 docs/TESTING.md。
