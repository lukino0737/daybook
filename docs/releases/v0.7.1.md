# Daybook v0.7.1

这次调整通知打开方式，并简化日历页面与编辑页提示。

- 点击应用通知先进入只读详情，查看完整正文、图片、日期及提醒规则；右上角的小号「编辑」按钮进入编辑页，保存或退出后回到详情。便签仍使用原有自动保存方式。
- 支持任务、日程、便签和独立提醒的通知。已有编辑草稿会先保留，保存或退出后再打开通知内容；已删除的内容会提示并禁用编辑。
- 在日历页，任务只显示在「近期截止」，不再出现在月历日期标记和下方当天列表。任务页、完成状态和通知提醒保持原有行为。
- 移除插图下方的大小/压缩说明和提醒编辑页的暂停/日历开关说明，相关功能不变。

Android 8.0+，版本0.7.1/code9，Room6/ZIP JSON6不变。普通功能可离线使用，可选AI功能继续由用户在设备内配置DeepSeek API Key。

建议先导出备份，再直接覆盖安装APK，勿先卸载。APK使用原签名，源码ZIP对应本次发布提交；SHA256清单用于核验附件。

真实DeepSeek效果及v0.7系列真机效果仍未验证；本次模拟器专项不等于所有机型均已验证。已知历史测试边界见docs/TESTING.md。

69项JVM、9项普通字号与4项150%字号专项通过，Lint无错误；已在API35模拟器验证真实v0.7.0原签名覆盖升级和正式启动，样例数据及通知渠道保留。详细验证范围见docs/TESTING.md。
