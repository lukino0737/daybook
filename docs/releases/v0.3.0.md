# Daybook v0.3.0

这次更新集中处理日历、回顾和提醒的使用反馈，保留原有纸面风格。

- 底部固定日历、任务、回顾；任务显示未完成数量，并按有无截止日期分区。新增按钮简化为加号。
- 日历缩小日期格，左右滑动换月；按需显示「今天」与日期差。事项使用小标记。
- 「安排」更名「日程」；日程和记录必须有日期，任务可用叉号清除日期。
- 回顾列出全部类型，默认全部类型/标签/时间；支持日期范围，点击筛选才应用，全默认先确认。
- 内置 2025/2026 中国大陆放假调休及常用节日：蓝点放假、红点补班、绿点个人事项。
- 提醒设置独立成页，带返回键，删除冗余提示和手动重新检查；保留后台自动核对。
- 新安装默认系统通知声、振动和高重要性；旧渠道设置保留，请在系统设置中按需开启声音、振动与悬浮。
- 更新 README 图片及使用说明。

直接覆盖安装即可，勿先卸载。同签名从 v0.2.0 升级已验证，数据库、标签、提醒及通知渠道设置保留；建议更新前导出备份。

32 项 JVM 单测、19 项常规模拟器用例、权限拒绝、大字体及覆盖升级专项通过。实际手机静音、声音、振动和悬浮效果仍需试用；系统与厂商设置决定最终提示方式。

Android 8.0+，完全离线。官方调休表与清明名称仅覆盖 2025/2026，后续随安装包更新。图文教程、照片、生日循环和同步不在本次更新。
