# Daybook v0.7.0

本次加入可选的DeepSeek AI助手，并修复完成一条任务时其他任务跟着变暗的问题。

- 普通多轮聊天，可选择模型与深度思考；聊天只保留在应用进程内，退出页面仍保留，进程结束后清空。
- 自然语言单条/多条录入、便签整理与待办提取、任务拆解、草稿多轮修改。可逐条编辑、勾选，确认后才保存；任务没有明确日期时不设截止。
- 个人事项按需查询，显示读取范围、本地统计和可打开来源；支持阶段回顾并生成便签草稿。普通聊天不预先上传记录，可关闭数据读取并清除旧上下文。
- 便签整理可另存或确认替换正文；含图便签仅另存文本，原图文保留。AI不读取图片，也不能自行删除、完成或改期。
- 完成反馈只作用于当前任务，其他任务仍可操作；重复点击和过时操作有保护。

Android 8.0+；版本0.7.0/code8，Room6/ZIP JSON6保持不变。普通功能仍可离线使用，无需账号或服务器。AI设置中填写自己的DeepSeek API Key，消息和按需读取的文字会发送给DeepSeek并使用你的API额度。Key在本机加密保存，不含在备份中；本地不保存长期聊天不代表API服务商不保留请求。

请先导出备份，再直接覆盖安装APK，勿先卸载。模型列表连接检查不等于生成效果验证。单轮读取有数量和长度上限；没有独立完成时间，不能把更新时间当作完成时间。

69项单元测试、分阶段模拟器专项和CI通过；AI测试使用假服务与虚构数据。真实DeepSeek效果及v0.7真机尚未验证，请保存前核对日期和内容。旧提醒取消通知用例组合运行有过一次失败，未改用例独立复验通过，原因未确定；详细证据见docs/TESTING.md。
