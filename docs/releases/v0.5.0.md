# Daybook v0.5.0

这次更新完善相册与主题配色，并让任务完成、便签编辑和删除操作更顺手。

- 图片权限与应用内相册：支持全部或部分图片授权、按相册筛选、补选图片；拒绝授权仍可用系统选图或文件入口。
- 完整调色盘：色相圆盘、色相/饱和度/明度滑块和常用色；支持无背景独立配色，或切回背景取色。预览后应用，返回取消。
- 任务页增加可折叠的已完成分区。完成时勾选、划线并过渡归类，再次点击勾选框可恢复。
- 任务、便签及日历当天事项支持左滑展开删除按钮，点击后二次确认。记录类保留短时撤销。
- 日历选中过去日期时，新建默认是记录；今天和未来仍默认日程。
- 便签顶部「完成」保存并退出，删除移到底部。新建空便签直接取消；已有便签清空后可保留已保存内容退出，或明确删除。
- 删除指定的外观说明文字。

Android 8.0+，离线、无账号。Room 4 / JSON 4 保持不变，原签名覆盖安装；请先导出备份，再直接安装新 APK，勿先卸载。外观和图片仅保存在本机，不进入记录备份。

图库仅覆盖系统允许访问的图片，不包含其他应用私有图片或全部云端原图。各厂商权限界面、鸿蒙 6 真机尚未验证；既有提醒异常排查继续暂缓。测试详情见仓库 docs/TESTING.md。
