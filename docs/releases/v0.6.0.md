# Daybook v0.6.0

这次更新加入独立提醒、正文内插图和完整图文备份，并把新任务默认改为「不设截止日期」。

- 独立提醒：支持单次、每天、每周多选、每月、每年公历及每隔若干天，可暂停和恢复。
- 统一提醒列表：集中管理独立提醒和日程、任务、便签附带的提醒；通知可打开对应内容。
- 日历显示：独立提醒可以选择是否显示，年度提醒默认显示；补充自启动和后台电池策略引导。
- 正文内插图：日程、任务、记录和便签支持文字与图片混排，大图查看、缩放、切换和移除；每条最多9张，图片保存为本地处理副本。
- 完整ZIP备份：包含正文图片、图文顺序及独立提醒；兼容旧JSON1–5，恢复先校验、预览确认并保存完整快照，失败保留原数据。
- 新任务默认不设截止日期；任务页新建、日历类型切换、独立提醒切换均一致。编辑已有任务保留截止日期。

Android 8.0+，离线、无账号。版本0.6.0/code7，Room6/ZIP JSON6。请先导出备份，再直接覆盖安装新APK，勿先卸载。旧版本应用不能读取新图文备份；背景和配色仍仅保存在本机，不进入备份。

已在API35专用模拟器验证真实v0.5.0原签名覆盖升级、旧数据与外观保留及正式启动。

隐私便签和拖动排序需求已取消，本版不包含这两项功能。正文图片和备份未加密码保护。验收证据与限制见docs/TESTING.md。
