# 四项体验调整实施计划（2026-09-27）

用户已确认采用推荐方案；本文件记录本次实施与验收范围，版本号和正式发布按交付时实际记录。

1. 提醒列表复用左滑露出删除按钮与确认操作。独立提醒删除整条；任务、日程、便签只清除附带提醒，正文及其他字段保留。取消确认不写入；过期操作、恢复后操作不能误删新状态；重新调度并取消旧通知。
2. 正文改为单一原生编辑区域，与 Compose 页面集成。图片独占一行，光标之后可继续文字；保留旧 BodyBlock、Room6、ZIP JSON6，不引入编辑器依赖。验证已有图文无损往返、中文组合输入、选区替换/跨图片删除、图片导入失败、草稿重建、显式保存/取消和便签自动保存。
3. 现有只读预览改为居中卡片，卡片左上退出、右上编辑，长内容在卡片内滚动。背景使用仅在内存中的模糊页面快照，兼容最低支持系统；不保存真实页面截图。验证普通/大字号、图片缩放、编辑返回和删除失效。普通列表入口语义保持现状。
4. 日历当天无事项且无应显示的独立提醒时，不显示当天标题、节假日说明及空提示卡片；有内容则显示，保留近期截止、新增按钮和月历本身。

顺序：提醒与空态 → 连续图文 → 卡片预览 → 针对性验证及文档提交推送。

替代方案已讨论：多个去边框输入框的改动较小但仍有分块感；提醒连同业务记录删除有误删风险；纯遮罩的兼容成本更低但不符合模糊效果。用户选择上述推荐方案。

验证分层记录：JVM、模拟器与真机分开；既有真实 DeepSeek 与 v0.7 系列真机未验证边界保留。旧发布标签与附件不变，工作区原有两份需求记录保留并更新批准状态。
