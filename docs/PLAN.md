# 第一阶段实施计划

## 产品

单人、简体中文、离线安卓 App。月历周一开始、切换月份、回到今天；格子显示记录摘要与溢出数量；选中日期下方展示当天列表。固定记一笔入口，默认安排和选中日期。

统一表单包含标题、备注、类型、日期与可选时间。安排/记录必须有日期；任务允许无日期但不允许孤立时间。任务可以完成和恢复；其它类型不打勾、不逾期。

近期截止包含所有逾期和今天起七天内的未完成任务。未安排入口始终可见。支持修改、删除、短时撤销、草稿恢复，日期更新随跨日和前台恢复刷新。

## 数据与接口

稳定 UUID；本地日期/时间；创建和修改时间；Room 唯一持久来源，成功写入后反馈。版本化 JSON 完整导出；恢复先校验、预览、确认，保留替换前快照，事务替换。恢复不合并，损坏和未知格式不更改原数据。

## 里程碑

1. 工具链、GitHub 仓库、工程骨架、构建及安装验证。
2. 三类记录、表单、Room、编辑删除与当天列表。
3. 月历、截止规则、无日期任务、日期边界测试。
4. 备份恢复、草稿、错误处理、布局与大字体适配。
5. APK、文档、覆盖升级测试、版本发布；之后两周真实试用。

每个里程碑验证后提交并推送公开仓库 lukino0737/daybook 的 main。每次提交记录目的、验证和限制。独立修复允许额外提交。首次可用交付标记 v0.1.0，后续修复递增补丁号。

## 边界

第一阶段不做账号、同步、AI、系统通知、小组件、重复日程和订阅。手机需 Android 8.0+。模拟器与真机验证分别记录；没有真机访问时保留待验证项。
