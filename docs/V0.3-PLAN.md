# v0.3.0 已确认方案（2026-09-11）

保持简洁纸面 UI 与现有文案；只修改用户指定范围。节假日随 APK 内置，保留现有通知渠道，用户已明确同意实施。

## A：界面与筛选

- 底部固定日历、任务（未完成数量）、回顾；移除无截止页面。任务按有/无截止日期分区。
- 日历紧凑日期格，有事项用小标记；左右滑动换月，取消箭头。今天按钮按所选日期及显示月份控制，日期差用小字显示。新增按钮仅“+”。
- “安排”统一显示为“日程”，内部 EVENT 标识与数据库/备份格式不变。日程、记录必须有日期；任务用叉号清除日期及截止时间。
- 回顾默认全部类型/标签/时间，类型完整列举。自定义范围包含起止两天、结束默认今天，无日期任务只在全时间段出现。
- 只在点击筛选后应用条件；全默认先确认。编辑筛选条件不会立即改变已有结果。
- 验收：日期差、范围边界单测；滑动换月、底部固定、类型与日期规则、任务分区与数量、筛选确认/取消/应用和草稿重建仪器测试。
