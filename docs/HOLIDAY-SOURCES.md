## 实施与验证提醒

- 假期区间与节日本日分别处理，不要把放假第一天当作农历节日。
- 常用农历节日使用 Android ICU ChineseCalendar（API 24，项目最低 API 26），按中国时区的日历日期转换，闰月不重复节日；除夕由次日是否春节确定。
- 蓝点表示放假，红点表示调休上班，绿点表示个人事项；辅助功能描述提供相应含义。
- 2025/2026 之外不猜测放假与补班。清明名称仅覆盖已核对的 2025-04-04 和 2026-04-05。
- 已验证放假总数、区间两端、跨月、农历节日、手机时区变化和未覆盖年份。
- 农历与清明核对来源：[香港天文台 2025 公农历表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2025.pdf)、[2026 公农历表](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2026.pdf)。
- 公历常用节日与农历节日由规则计算；官方放假/补班及清明的年度数据后续随 APK 更新。
