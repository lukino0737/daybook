## 实施与验证提醒

- 假期区间与节日本日分别处理，不要把放假第一天当作农历节日。
- 常用农历节日可考虑 Android ICU ChineseCalendar（API 24，项目最低 API 26），尚未实现或验证；注意月份从 0 开始、闰月、除夕以及本地日期边界。
- 蓝点表示放假，红点表示调休上班，绿点表示个人事项；辅助功能描述提供相应含义。
- 2025/2026 之外不猜测放假与补班。清明日期另行核对，不用近似公式冒充完整节气数据。
- 编码后补充放假总数、区间两端、跨月、农历节日和未覆盖年份测试。
