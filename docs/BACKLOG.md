# 后续任务

## 2026-09-27 新需求：已实现并通过专项验收（main 尚未发布）

以下四点最初仅记录；用户随后明确要求实施，并确认推荐方案。当前实施范围与验收见 UX-IMPROVEMENTS.md。

1. **提醒列表左滑删除**：提醒列表也加入左滑删除操作；采用左滑露出按钮后确认；独立提醒删除整条，附带提醒只取消提醒并保留原内容。
2. **同一编辑框内连续图文**：文字和图片位于同一个编辑框内，形成「文字 → 下一行图片 → 下一行继续文字」的连续编辑体验，类似 Word 的上下型环绕。用户不满意现有「文字框 + 图片 + 文字框」的分块感；需求不仅涉及最终展示，也涉及插图和继续输入文字的体验。采用单一原生编辑区域，与Compose整合；继续使用原BodyBlock存储格式。
3. **居中卡片预览**：按本次用户提供的标注图表达布局意图：页面中间一个小卡片呈现预览内容，卡片之外的背景模糊，右上编辑、左上退出。短内容卡片自然收缩，长内容在卡片内滚动；左上退出、右上编辑。
4. **日历当天无内容时隐藏整段空态**：用户补充「框起来的东西直接去掉，没有东西就不写了」。按标注范围记录为：选中日期没有可展示内容时，不显示月历下方当天区域的日期标题、节假日说明，以及含图标和「这一天，留给你慢慢写。」「日程和生活片段，都可以记在这里。」的空白提示卡片；有内容时正常显示当天内容。右下角新增按钮保留，近期截止区域不受此项影响。此项已纳入确认方案。

参考图仅用于理解布局；不将含个人内容的原始截图保存或上传到仓库。实现保持现有数据格式与旧发布标签、附件。
