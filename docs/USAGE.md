# 使用说明

本说明对应 main 开发版 0.6.0-dev / code 7；本批未发布或交付新安装包，已发布版本仍为 v0.5.0。
## 记一笔

点日历中的日期，再点右下角「+」。选中过去日期时默认类型是记录，今天或未来默认日程，自动填入选中日期；标题必填，其余按需填写。

- 日程：课程、见面、发布会、游戏更新。日期必填，时间可以未定。
- 任务：需要完成的事。日期表示截止日；可点日期旁的叉号清除日期和时间。
- 记录：已经发生的生活片段，例如喝奶茶。日期必填，无需打勾。

仅设截止日的任务，当天结束后才算逾期；设置具体时间的任务，到该时间后即算逾期。完成后可在任务页下方的「已完成」分区、日历或回顾找到，并恢复为未完成。

## 日历与任务

日历年月合为一行；左右拖动日历可跟随手势切换月份，短距离拖动会回弹。点日期查看当天完整内容。选到其他日期或月份时，右上角出现「今天」，点击返回今天；旁边的小字表示选中日期距今天多少天。

日期下的绿点表示有个人事项；蓝点表示放假，红点表示调休上班。节日本日显示名称，选中日期可查看完整说明。官方放假调休数据与清明名称内置 2025/2026 年中国大陆资料，后续随安装包更新；未覆盖年份不推测放假或补班。常用公历、农历节日由日期规则显示。

底部固定「日历」「任务」「便签」「回顾」。任务旁数字是全部未完成任务数，与选中日期无关；列表上方是有截止日期的任务，下方是无截止日期的任务。任务完成时显示勾选和划线动画，随后归到下方「已完成」分区；点分区标题展开或收起，列表按最近修改排序。再次点勾选框恢复到原截止日期分区。「近期截止」显示逾期和今天起七天内的未完成任务。

点记录编辑，保存后更新。日历当天事项、任务页的未完成和已完成任务均可左滑展开删除按钮，点删除后还需确认；取消保留原内容。删除后可在底部提示中短时撤销。一次只展开一条，右滑、滚动或点卡片可收起。回顾和近期截止卡片仍从编辑页删除。

## 标签与回顾

类型决定记录的行为：日程、任务、记录。标签表示主题，例如恋爱、学习、旅行，可跨类型使用。编辑时用逗号分隔标签，也可以点选已有标签；最多 10 个，每个最多 30 字。

回顾默认全部类型、全部标签、全时间段。可以选择类型、标签，搜索标题/正文，或设置日期范围；结束日期默认今天，起止两天都计入范围。无日期任务仅在全时间段中出现。

点「筛选」后才显示或更新结果。没有设置条件时，会先询问是否回顾所有内容。修改筛选条件时，原结果保留到下次点击筛选。结果按日期倒序，无日期任务排最后。

「重置筛选」会同时清空所有已选条件、搜索词和已显示结果，回到等待筛选的状态。

点卡片标签会进入回顾并选中该标签，再点击筛选。回顾中新建默认是记录，编辑后保留筛选条件。正文支持 20000 字，目前没有照片。

## 独立便签

底部点「便签」再点「+」，直接输入所想，无需标题或日期。第一行非空内容作为列表摘要，按最近修改排序；需要时可加日期或独立提醒。便签是独立内容，不属于第四种记录类型，也不混入日历、任务或回顾。

正文自动保存，右上角「完成」和左上角返回都会确保保存后退出。空的新便签（包括本次新建后输入又清空）直接取消创建。已有便签清空后，可选择保留上次保存的内容并退出，或删除便签；删除仍需确认。保存失败会明确提示并留在编辑页，可重试。正文最多 20000 字。

编辑页底部提供「删除便签」；列表左滑也可展开删除按钮，点击后再次确认。删除便签会同时移除其日期和提醒，便签删除没有撤销入口。

## 自定义背景

右上角菜单 →「外观设置」→ 选择图片 → 查看背景与按钮配色预览 →「应用」。返回可放弃预览，「恢复默认」恢复原纸面外观。四个主页共享背景，编辑和设置保留清晰底色；放假、补班、个人事项标记和错误色保持各自含义。

图片在本机生成副本并提取主题色，不上传。过大或无法解码的图片会提示重新选择，原外观保留。外观与图片不包含在 JSON 记录备份中，换机后需重新选图。

点击选择背景时申请图片访问权限。允许全部后可以浏览系统媒体库中的图片并按相册筛选；只允许部分时，使用「管理可访问图片」补选，或进入「权限设置」调整授权。拒绝时仍可使用「系统选图」或「从文件选择」。全部授权不包含其他应用私有目录、隐藏媒体或尚未下载的云端原图。

提供色相圆盘、色相/饱和度/明度滑块及常用色块；可以不选背景而独立设置主题色，也可切回「跟随背景取色」。更换背景会保留手动配色。调整仅用于预览，点击「应用」后保存，返回放弃本次调整；「恢复默认」同时重置背景与配色。实际界面颜色会为文字对比度作适当调整。图片与配色仍只保存在本机，不进入记录备份。

## 独立提醒与统一列表

新建「记一笔」时选择第四个入口「提醒」，或从右上角菜单「提醒列表」点「＋」。输入标题、可选备注、日期和时间，选择单次、每天、每周（可多选星期几）、每月、每年公历或每隔 1–9999 天；核对下一次时间后保存。保存失败会保留草稿，取消不会保存。便签页的「＋」仍直接创建便签。

重复始终以起始日期为基准：每月31日会跳过没有31日的月份；每年2月29日只在闰年发生，不提前到月底。单次提醒新建或重新设定时必须在未来。重复提醒从保存后开始，不补发创建以前的次数。每条只有一个时刻，没有完成勾选、截止状态或结束次数。

「显示在日历」决定是否在发生日期显示事项点和当天的提醒分区。新建年度提醒默认开启，其余默认关闭；手动选择后，切换重复规则不会覆盖选择。日历中的每次显示对应同一条提醒，编辑或删除作用于整条；暂停仅停止通知，不改变日历开关。独立提醒不进入任务数量或回顾。

「提醒列表」集中展示独立提醒，以及日程、任务、便签附带的一次提醒。待提醒按下次时间排序；已暂停、已结束默认折叠，按最近修改排序。点击附属提醒会打开原内容。任务完成后其提醒归入已结束。启用开关在独立提醒编辑页中，改动后需保存。

每条重复提醒最多补发过去24小时内最近一次，恰好满24小时及更早的跳过。暂停期间不补发，恢复后安排未来次数；过期的单次提醒需先改到未来时间才能恢复。改标题、备注或日历显示不会重发；改日期、时间或重复规则会重新安排未来次数。

点击通知打开对应内容。如果有未关闭的编辑草稿，先保留草稿，保存或取消后再打开通知目标。已删除的独立提醒会提示并返回提醒列表。年度仅支持公历；本批不包含农历、重复任务、多时段或某一次的例外修改。

## 设置提醒

v0.4.0 新增：首次打开时，Android 13 及以上在尚未授权的情况下请求通知权限；允许、拒绝或关闭弹窗后，显示一次可跳过的提醒设置引导。Android 8–12 无此系统通知授权弹窗，直接显示引导。选择「去设置」「稍后设置」或返回后，引导不再自动出现；升级前未使用过此引导的安装也会显示一次。

编辑日程、任务或便签时打开「提醒」，选择提醒日期和时间。提醒时间独立设置，修改发生或截止日期不会自动移动提醒；无日期任务也可以设置提醒。

点编辑页的「提醒设置」，或右上角菜单中的同名入口，进入独立设置页。需要同时开启通知与准时提醒。左上角返回编辑页时，未保存的输入会保留。默认不为新记录开启提醒。

新安装默认使用系统通知声、振动和高重要性通知。旧版覆盖升级保留原通知渠道设置：如果振动或声音关闭，请点「声音、振动与悬浮设置」在系统中开启。静音时是否振动、是否悬浮，由系统模式、渠道设置与厂商策略共同决定；App 不绕过静音或勿扰设置。

提醒设置另提供「自启动与后台运行」和「悬浮通知」建议，按品牌显示说明。小米/红米/POCO、华为/荣耀、OPPO/一加/realme、vivo/iQOO 尝试对应设置入口；三星提示检查休眠应用；其他品牌提供通用后台设置说明。入口不可用时转到 Daybook 系统应用详情页，仍可按说明手动查找。自启动和悬浮开关以系统设置为准，不在 App 中猜测开启状态。

请开启 Daybook 自启动，并在电池或耗电管理中选择「无限制」或机型对应的允许后台运行选项。可从提醒设置的「设置电池策略」进入应用详情。厂商无限制与系统电池优化豁免不是同一个开关，App 不猜测其开启状态。用户最新实测反馈支持同时开启自启动和无限制；机型差异仍需以实际送达为准。已看过旧引导的安装，在首次使用提醒功能时会补充一次可跳过说明，不重复请求已拒绝的通知权限。

点击通知可打开对应记录或便签。删除、完成任务、清除或修改提醒后会自动核对调度，旧通知会取消；相同提醒已发出后不重复。系统重启、更新、时区/时间变化及返回 App 时也会自动核对，无需手动重新检查。

过去 24 小时内未发出的提醒可能补发，并注明补发；更旧的不补发。系统强行停止 App 后需重新打开，品牌省电策略也可能影响送达。

## 备份与恢复

通过右上角菜单导出 JSON 到手机文件夹或自行选择的文件服务。备份包含原三类记录、便签、独立提醒及其规则和发送状态，请妥善保存。

恢复时先选文件，完整校验后显示数量。确认后保存包含记录、便签和独立提醒的本地快照，再替换当前全部内容；空备份也会清空列表，不合并记录。菜单中的「恢复替换前快照」可退回最近一次替换前的数据；快照仍在本机，不能代替外部备份。

恢复不含便签的旧备份会清空当前便签；恢复 JSON 1–4 的备份会清空当前独立提醒。确认页会明确说明并显示三类数据数量；需要时可以从替换前快照找回。

升级请直接安装同签名的新 APK，不要先卸载。卸载会清除数据库和快照。

## 当前范围

0.6.0-dev 使用数据库 5 与 JSON 格式 5，可读取 JSON 1–5 的备份并安全迁移旧数据库。本批正式签名包覆盖升级尚未验证。没有自动同步、重复日程、农历生日、正文照片或 AI 录入；完整图文教程留后续。提醒跟随本地钟表时间，跨时区不保持原时区的绝对时刻。
