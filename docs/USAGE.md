# 使用说明

## 记一笔

点日历中的日期，再点“记一笔”。默认类型是安排；标题是唯一必填文字，其余按需填写。

- 安排：课程、见面、发布会、游戏更新。日期必填，时间可以未定。
- 任务：需要交付或完成的事。日期表示截止日，可勾选完成；没有日期时进入“无截止”。
- 记录：已经发生的生活片段，例如喝奶茶。无需打勾。

仅设截止日的任务，整天都不算逾期；第二天开始才算。设置具体时间的任务，到该时间后即算逾期。完成后仍保留在原来的日期，可取消完成。

## 查看与修改

月份左右箭头切换月份，“今天”回到当前日期。月历文字过多时显示额外条数，点日期查看完整列表。

“近期截止”显示逾期和今天起七天内的未完成任务。“待完成”可看全部未完成任务，“无截止”可看无截止日期的任务（包括已完成项），旁边数字是该列表总数。“待完成”旁边数字只统计未完成任务，与日历日期无关。

点记录编辑，保存后更新。删除需确认，删除后底部提示中的“撤销”可短时恢复；提示消失后需依赖此前备份恢复。

## 备份与恢复

使用菜单中的导出备份，将 JSON 保存到手机文件夹或自行选择的文件服务。文件包含完整日历内容，请妥善保存。

恢复时先选文件，应用校验后显示记录数量。只有确认替换后才更改当前数据；零条记录的备份也会清空当前列表，因此务必看清预览。

每次替换前会保留最近一份本地快照。“恢复替换前快照”可预览并恢复；恢复快照本身也会保存当时的现有数据，支持退回最近一次替换。该快照仍在本机，不等于外部备份。

卸载会清除本地数据库与快照。升级请直接安装同签名的新 APK，不要先卸载。

## 设置提醒

编辑安排或任务时打开“提醒”，选择提醒日期和时间。提醒与发生/截止时间独立：例如晚上截止的任务可以下午提醒，修改截止时间不会自动移动提醒。没有截止日期的任务也可以设置一个提醒时间。

在编辑页或右上角“提醒设置”中开启通知和准时提醒权限。两者齐全才会调度；没有权限时记录仍会保存，首页会显示尚未启用。默认不开启任何提醒。

点击通知直接打开记录。删除、完成任务、清除或修改提醒后会重新核对调度，旧通知会取消；相同提醒已发出后不重复。重新设置提醒可再次启用。系统重启、更新、时区/时间变化或返回 App 时也会核对。

过去 24 小时内未发出的提醒可能补发，并显示“补发提醒”；更旧的提醒不补发。恢复旧备份后也遵循此规则。手机设置中强行停止 App 后，需重新打开才能恢复调度；品牌省电策略可能影响通知。

## 标签与回顾

编辑时输入标签，用逗号分隔，也可以点选已有标签。最多 10 个，每个最多 30 字；自动去掉首尾空格和重复项。

“回顾”默认只看生活记录；可切换“全部类型”。点“恋爱”等标签会列出匹配内容，搜索框同时匹配标题或正文。标签与搜索一起生效，清除筛选可回到完整列表。结果按日期倒序，无日期任务排在最后。

点卡片上的标签可直接打开相关内容。在回顾中新建默认是生活记录，编辑保存后保留当前筛选条件。正文可写 20000 字；目前不支持照片。

## 本阶段限制

没有自动同步，备份恢复是整份替换，不会合并记录。当前不支持重复日程、生日自动循环、照片、自定义背景和自然语言识别。提醒跟随本地钟表时间，跨时区不会保持原时区的绝对时刻。

v0.2.0 可恢复 v0.1.0 的旧备份；新版备份增加标签和提醒字段，不能交给旧版恢复。
