- 快照创建回调抛错，数据库不变。
- SQLite 触发器让恢复插入失败，之前的清空操作一起回滚。

- 空备份显示清空提醒；取消不更改数据，确认后可通过快照恢复。
- 备份恢复后，旧的删除撤销不能污染新数据集。
